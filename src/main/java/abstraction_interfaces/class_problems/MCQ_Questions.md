# Week 8 – MCQ Quiz

## Questions and Answers

1. **Which OOP concept allows the same method or interface to behave differently for different objects?**  
   **Answer:** Polymorphism

2. **Which OOP concept bundles data and methods together and controls access to the data?**  
   **Answer:** Encapsulation

3. **An Author can write one or more Books. What is the UML multiplicity?**  
   **Answer:** One Author to one or more Books (Author 1 — Book 1..*)

4. **Which relationship represents a strong whole-part relationship where the part's lifecycle depends on the whole?**  
   **Answer:** Composition

5. **Which UML relationship represents inheritance between a general class and a specialized class?**  
   **Answer:** Generalization

6. **Which UML relationship represents a class implementing an interface?**  
   **Answer:** Realization

7. **Which relationship represents a general link between independent classes?**  
   **Answer:** Association

8. **Which UML diagram represents the states of an object and transitions between those states?**  
   **Answer:** State diagram

9. **Which OOP concept exposes essential features while hiding implementation details?**  
   **Answer:** Abstraction

10. **Which UML diagram shows interactions/messages between objects in time order?**  
    **Answer:** Sequence diagram
