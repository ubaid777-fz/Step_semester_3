# Week 9 – Conceptual Questions and Answers

## Question 1

An unsorted array requires linear search, which takes time in the worst case because each element may need to be checked. A sorted array allows binary search, which takes time because the search space is halved at each step. The difference is that sorting enables us to eliminate half of the remaining elements after each comparison.

## Question 3

Linear data structures, such as arrays, store elements in a sequential order and are typically traversed one element after another. Non-linear data structures, such as trees, organize elements hierarchically, with parent-child relationships and potentially multiple branches. Therefore, tree traversal follows specific strategies such as preorder, inorder, postorder, or level-order rather than simply moving through a single sequence.
